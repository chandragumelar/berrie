# Checkpoint fondasi

Direktori ini memuat snapshot repo root lokal Berrie pada commit `85e7d5b`. Snapshot ditempatkan di sini agar PR tetap berbasis riwayat `main` prototipe tanpa menggabungkan dua riwayat Git yang tidak berhubungan. Root repo GitHub di luar direktori ini tetap prototipe Sites; dalam dokumen snapshot, rujukan `berrie-site/` menunjuk ke root repo GitHub tersebut. Snapshot mempertahankan jalur dan teks lokal apa adanya; tautan relatif ke `berrie-site/` perlu penyesuaian saat menentukan tata letak repo final.

T-01 selesai. T-02 dan T-03 masih berjalan, dan aplikasi belum siap untuk transaksi operasional. Lihat `tasks.md` dan `app/README.md` dalam direktori ini untuk bukti dan batas. Tidak ada izin deployment, provisioning, DNS atau merge dalam checkpoint ini.
